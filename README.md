# «Қадам» — математикалық жұмыстарды тексеретін ЖИ-көмекші

Оқушының қолжазба шешімін суреттен оқиды, БЖБ дескрипторлары бойынша қадамдап талдайды,
қатенің түрі мен орнын көрсетеді, қатеге сәйкес жаттығулар құрастырады және сынып бойынша
қателер картасы мен БЖБ талдауын жасайды. Соңғы бағаны мұғалім растайды.

---

## 1. Интернетте жариялау (≈30 минут, тегін)

### 1-қадам. Gemini API кілтін алу
1. https://aistudio.google.com/apikey сайтына Google аккаунтымен кіріңіз.
2. **Create API key** батырмасын басыңыз да, кілтті көшіріп алыңыз.
3. Кілтті ешкімге көрсетпеңіз және презентацияға, видеоға салмаңыз.

### 2-қадам. Кодты GitHub-қа жүктеу
1. https://github.com сайтында аккаунт ашыңыз.
2. **New repository** басып, атауын `qadam` деп жазыңыз (Public). Содан кейін **Create** басыңыз.
3. **uploading an existing file** сілтемесін басыңыз да, `qadam` қалтасындағы барлық файлдар мен қалталарды сүйреп әкеліңіз.
   `.streamlit/config.toml` файлы да жүктелуі керек.
4. **Commit changes** батырмасын басыңыз.

### 3-қадам. Streamlit Cloud-та іске қосу
1. https://share.streamlit.io сайтына GitHub аккаунтымен кіріңіз.
2. **Create app → Deploy a public app from GitHub** таңдаңыз.
3. Repository: `қолданушы-атыңыз/qadam`, Branch: `main`, Main file: `app.py`.
4. **Advanced settings → Secrets** өрісіне мынаны жазыңыз:
   ```
   GEMINI_API_KEY = "көшірілген-кілтіңіз"
   ```
5. **Deploy** басыңыз. 2–3 минуттан кейін сайттың сілтемесі дайын болады (`https://....streamlit.app`).
   Осы сілтемені өтінімдегі «жобаның жұмыс істейтін нұсқасының мекенжайы» өрісіне жазасыз.

> Streamlit Cloud ұзақ уақыт пайдаланылмаған қосымшаны «ұйықтатады». Ашқан адам
> «Yes, get this app back up!» батырмасын басса, сайт шамамен 1 минутта қайта қосылады.

## 2. Компьютерде іске қосу (міндетті емес)
```
pip install -r requirements.txt
streamlit run app.py
```
Кілтті `.streamlit/secrets.toml` файлына жазыңыз (`secrets.toml.example` файлында үлгісі бар).

## 3. Пайдалану нұсқаулығы (комиссия мен мұғалімге)
1. Сол жақтағы тізімнен БЖБ-ны таңдаңыз. Екі үлгі БЖБ дайын: 5-сынып «Жай бөлшектер», 6-сынып «Пропорция».
   Өз БЖБ-ңызды **БЖБ баптау** бетінде Word, PDF, JSON файлынан немесе кестеден қосасыз. Үлгі пішіндегі Word-ты
   бағдарлама ЖИ-сіз оқиды, басқа Word пен PDF-ті ЖИ бөліктерге ажыратады, мұғалім тексеріп сақтайды.
2. **Жұмысты тексеру** бетіне оқушы кодын енгізіңіз (мысалы `5А-12`) және жұмыстың суретін жүктеңіз.
   Суретте дербес дерек жоқ екенін растап, **Тексеру** батырмасын басыңыз.
3. ЖИ нәтижесін қараңыз. 🔴 белгісі бар бағаларды міндетті түрде тексеріңіз. Қажет болса,
   «Мұғалім ✏️» бағанында ұпайды өзгертіңіз. Содан кейін **Растау және сақтау** батырмасын басыңыз.
4. **Ұқсас жаттығулар** батырмасы оқушының қатесіне сәйкес тапсырмалар береді.
5. **Сынып нәтижелері** бетінде қателер картасы, дескрипторлар, БЖБ талдау мәтіні және Excel бар.
6. **Тиімділік** бетінде ЖИ мен мұғалім бағасының сәйкестігі және үнемделген уақыт көрсетіледі.
7. Жұмыс соңында сол жақтағы **Жұмыс файлын сақтау** батырмасын басыңыз. Келесі жолы сол файлды жүктесеңіз, нәтижелер қайта ашылады.

## 4. Құрылымы
| Файл | Мазмұны |
|---|---|
| `core/ai.py` | ЖИ промпттары, Gemini-мен байланыс, ЖИ жауабын тексеру |
| `core/taxonomy.py` | Математикалық қателер классификациясы |
| `core/importer.py`, `core/docparse.py` | Word және PDF БЖБ-ны оқу |
| `core/verify.py` | Жаттығулардың жауабын жай бөлшектермен дәл тексеру |
| `core/stats.py` | Сынып статистикасы, ЖИ дәлдігі, Excel |
| `core/privacy.py` | Оқушы коды өрісінің пішінін тексеру |
| `data/bjb/*.json` | Үлгі БЖБ спецификациялары |
| `views/*.py` | Беттер |
| `tests/` | Автоматты тесттер (`python -m pytest tests`) |

## 5. Әзірлеу және дайын компоненттер
- Бағдарлама коды, интерфейс, промпттар, қателер классификациясының және екі үлгі БЖБ-ның бастапқы нұсқасы **Claude (Anthropic) ЖИ-көмекшісімен** жазылды. Команданың үлесі жоба паспортында көрсетіледі.
- **Дайын компоненттер:** Google Gemini (ЖИ моделі), Streamlit, pandas, Pillow, openpyxl.

## 6. Деректер және шектеулер
- Жұмыс суреті (және ЖИ-мен оқылатын БЖБ файлы) Google Gemini-ге жіберіледі. Тегін тарифте Google жіберілген деректерді қарап, модельдерін жетілдіруге пайдалануы мүмкін. Сондықтан дербес дерегі бар файл жүктемеңіз.
- Тегін тарифтің лимиті шектеулі: 2026 жылғы 24 қарашада екі модельде күніне 20 сұраудан байқалды. Ақылы тарифтің құны Google-дың ағымдағы бағасына байланысты.
- Серверлер жүктелгенде жауап бірнеше минутқа созылуы немесе келмеуі мүмкін.
- ЖИ тек ұпай ұсынады. Соңғы бағаны мұғалім қояды.
